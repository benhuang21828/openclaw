# Finance Tools

Use these tools to get real-time market data.

## Scripts

### Get Stock Price
Get the current price and summary for a ticker.
```bash
node openclaw/skills/finance-tools/scripts/get-price.js AAPL
```

### Search Ticker
Search for a ticker symbol by company name.
```bash
node openclaw/skills/finance-tools/scripts/search-ticker.js "Nvidia"
```
